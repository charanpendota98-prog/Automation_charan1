=== StudentUp Rank Math Automation Bridge ===
Contributors: studentup
Tags: rank-math, rest-api, seo, automation
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.1.0

Saves Rank Math focus keyword, SEO title, description and social fields through an authenticated, allow-listed REST endpoint. It never writes a local estimate into Rank Math's score fields; the official score remains the value shown by Rank Math in the WordPress editor.

== Installation ==
1. Upload studentup-seo-bridge.zip in Plugins > Add New > Upload Plugin.
2. Activate the plugin.
3. Keep Rank Math active.

Only an authenticated user who can edit the target post may use the endpoint.
